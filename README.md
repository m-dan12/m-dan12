## Избранные проекты

### CutSheet — автоматическое составление монтажных листов

Система помогает подготовить монтажный лист по видео и сценарию: выделяет планы, распознаёт речь, сопоставляет реплики со сценарием и собирает черновик для проверки человеком.

- Детекция границ планов и извлечение ключевых кадров.
- Разбор сценария, распознавание речи и сопоставление диалогов.
- Определение крупности плана и генерация описаний с помощью мультимодальной модели.
- Десктопный клиент со встроенным плеером, редактором таймкодов и реплик. Ручные правки сохраняются при повторной обработке.
- Экспорт в Excel, Word и PDF.

Архитектура построена вокруг событий Kafka: C#- и Python-сервисы обрабатывают отдельные этапы конвейера. PostgreSQL хранит состояние проектов, MinIO — видео и результаты обработки, SignalR передаёт обновления клиенту. Предусмотрены повторы, очередь неудачно обработанных сообщений, метрики и распределённые трассировки.

**Стек:** C#/.NET, Python, Flutter, Kafka, PostgreSQL, MinIO, SignalR, Docker Compose, PySceneDetect, Whisper, MediaPipe, LLM, Prometheus, Grafana, Jaeger.

[Репозиторий →](https://github.com/m-dan12/cutsheet)

### Radial Menu — радиальное меню для Windows

Совместный проект: коллега создал прототип на Python, я доработал интерфейс, расширил функциональность и перенёс приложение на Rust с целью снизить потребление оперативной памяти и процессора.

Меню позволяет запускать приложения, выполнять сочетания клавиш и последовательности действий, управлять мультимедиа и создавать заметки в Obsidian. Поддерживает вложенные и контекстные меню, несколько способов вызова, темы, настройки и обновления.

В Rust-версии применяются предварительная отрисовка элементов, обновление только изменившейся области и обработка событий вместо постоянной перерисовки в простое.

**Стек:** Rust, Win32 API, tiny-skia, resvg, YAML.

[Репозиторий коллеги →](https://github.com/203225014/RadialMenu)

Приложение для Windows и Android: принимает созданные нейросетью анкеты персонажей и существ в TOML, проверяет данные по JSON-схемам и рассчитывает характеристики по правилам игры. Есть библиотека карточек и экспорт в PDF.

**Стек:** TypeScript, React, Electron, Capacitor, Ajv, React PDF.

[Репозиторий →](https://github.com/m-dan12/kodeks)
